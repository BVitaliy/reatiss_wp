# JavaScript Standards

## Never edit vendor files
Files in `js/vendors/` are third-party and are regenerated by `gulp updateJS` —
any hand edit is lost on the next run. All custom JS lives in `js/app-*.js`.

## Keep the markup's JS structure
The static markup ships one `app-*.js` per feature (`app-menu.js`, `app-swiper.js`,
`app-home.js`…). Keep that split — do not merge them into one bundle. Enqueue
per-page files conditionally in `functions/init.php`, mirroring how the original
page templates included them.

## Modules must guard their own root element
The same script is enqueued on several templates, so every module bails when its
DOM is absent instead of throwing.

```js
// ✅
const root = document.querySelector( '.home-gallery' );
if ( ! root ) return;
```

## AJAX — always use the localized nonce
```js
// ✅
fetch( reatiss.ajaxUrl, {
    method: 'POST',
    body: new URLSearchParams( {
        action: 'rts_load_more',
        nonce:  reatiss.nonce,
        page:   nextPage,
    } ),
} )
    .then( r => r.json() )
    .then( data => {
        if ( ! data.success ) return;
        // handle response
    } );
```

## Debounce filter and search inputs — 300ms
```js
// ✅
let timer;
input.addEventListener( 'input', () => {
    clearTimeout( timer );
    timer = setTimeout( applyFilter, 300 );
} );
```

## No alert() — inline messages only
```js
// ✅
document.querySelector( '.form__notice' ).textContent = 'Сталася помилка';

// ❌
alert( 'Error' );
```
